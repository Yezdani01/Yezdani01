## 🚀 Featured Projects

### EduRAG — AI Teaching Assistant

A multimodal Retrieval-Augmented Generation application that
allows students to interact with educational videos, audio
recordings and documents through natural language.

- Semantic search and context-aware responses.
- Video timestamps and document references.
- Multimodal content processing.
- Published research project.

**Tech:** Python, LangChain, Whisper, LLMs, Streamlit

### E-Commerce Backend API

A modular backend application for an e-commerce platform,
built with FastAPI and PostgreSQL.

- RESTful API architecture.
- JWT-based authentication.
- Password hashing and user management.
- SQLAlchemy ORM and database relationships.
- Automated API documentation using Swagger UI.

**Tech:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pydantic, JWT

### Conversational AI Agent

An AI agent with persistent conversational memory and
execution monitoring.

- Context retention across conversation turns.
- Tool execution and trace monitoring.
- Token usage and latency tracking.

**Tech:** Python, Agentspan, GPT-4o Mini, SQLite

### AWS Customer Agreement Assistant

A local RAG application for querying and understanding
complex legal documentation.

- Context-aware document retrieval.
- Local LLM integration.
- Query analytics and performance monitoring.

**Tech:** FastAPI, Streamlit, Ollama, Llama 3, SQLite
